# رحلاتي

مخطط رحلات عام يدعم **أي دولة وأي مدينة**: https://almohammdin.github.io/services/trips/

- الرحلات منفصلة بحسب الاسم والمدينة والدولة. إنشاء رحلة جديدة يبحث عن المدينة عبر Nominatim عند الطلب، ثم يعرض خريطتها؛ في حالة تعذر البحث يمكن تحديد الموقع يدويًا.
- يتم نقل قائمة إسطنبول السابقة من localStorage عند أول استخدام. إسطنبول مجرد مثال لأول رحلة، وليست اسم المنصة أو وجهة مفروضة.
- إضافة الأماكن، خريطة، تصنيفات، تنظيم أولي بحسب قرب المسافات، تصدير واستيراد كل الرحلات، مقترحات للمحتوى.
- تنبيهات القرب تعمل أثناء فتح واستخدام الموقع فقط. التنبيه بالخلفية على iOS يحتاج حلًا أصليًا أو بنية إضافية؛ موقع PWA وحده لا يوفر تتبع الموقع في الخلفية.
- اقتراحات الاستكشاف المثبتة والمحققة لإسطنبول تبقى ضمن رحلتها. المدن الأخرى تقبل إضافة أي جولات وأماكن، والمقترحات العامة المحلية الآلية قيد التطوير.
- في هذه النسخة البيانات محفوظة محليًا لكل متصفح ولا يوجد حساب سحابي أو تزامن تلقائي.
- تخطيط الأيام تقريبي يعتمد على المسافة الجغرافية وتقديرات زمنية، وليس تحسينًا دقيقًا لشبكات المترو والترام والعبّارات.

المجلد `istanbul-trip/` يحوّل الزوار للنسخة العامة `trips/`.

## قسم الأدوات (2026-11-14)

- تبويب «الأدوات» يقدم كتالوجًا من التطبيقات والخدمات مصنفًا حسب الاستخدام: النقل، الحجز، الدفع، الترجمة، الخرائط، والعملات وغيرها.
- يعتمد الاختيار على الدولة والمدينة للرحلة النشطة: الأدوات العامة تظهر في جميع الوجهات، وتظهر التطبيقات الخاصة بتركيا وإسطنبول والصين عندما تنطبق الوجهة. هذه قائمة تأسيسية قابلة للتوسيع وليست دليلًا شاملًا لكل دولة.
- أدوات الرحلة التي يحددها المستخدم (زر «أحتاجها») وأي رابط يضيفه يدويًا تحفظ لكل رحلة ضمن بيانات المتصفح المحلي، وتدخل ضمن النسخة الاحتياطية لكل الرحلات.
- الكتالوج منفصل قابل لإعادة الاستخدام في أي منصة أخرى عبر `tools-catalog.js`، ويمكن تحميله عبر `https://almohammdin.github.io/services/trips/tools-catalog.js`. يُنصح لاحقًا بتحويله لواجهة بيانات قابلة للتحديث مركزيًا ومراجعة صلاحية الروابط بانتظام.
- يمكن إدخال أداة مخصصة بأي فئة طالما رابطها يبدأ بـ HTTP أو HTTPS. بيانات الروابط المستوردة تُعرض بأمان بعد التحقق من البروتوكول.
- دليل الأدوات لا يتصل بواجهات برمجة خدمات الحجز أو الدفع؛ فتحها حاليًا ينقلك إلى المصدر الأصلي فقط. لا توجد مزامنة تلقائية لتنزيل التطبيقات أو التحقق من توفر المقاعد والأسعار.
