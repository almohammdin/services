# إسطنبول على مهل · مخطط الرحلة

نسخة تجريبية منشورة ضمن مستودع الخدمات على GitHub Pages: https://almohammdin.github.io/services/istanbul-trip/

## وظائف النسخة الحالية

- خريطة تفاعلية عبر Leaflet وOpenStreetMap ونقاط الأماكن.
- إضافة المواقع يدويًا، أو التقاط الإحداثيات من بعض روابط Google Maps الطويلة، أو لمس الخريطة.
- حفظ قائمة الأماكن والجدول في localStorage على الجهاز الحالي؛ تصدير/استيراد JSON للنقل والنسخ الاحتياطي. لا توجد مزامنة تلقائية بين الأجهزة.
- ترتيب تجريبي حسب المسافة التقريبية، الأيام، مدة الزيارة. الزمن المتوقع ليس ناتجًا من منصة نقل مباشر ولا يحسم تعارضات المواعيد الثابتة.
- خمس أفكار استكشاف: مشي على القرن الذهبي، بالات وفنر، عبّارة البوسفور، مودا، ودراجة جادّه بوستان. نقاطها مؤشرات تقريبية وليست مسارات مكتملة.
- مراقبة موقع بعد الإذن، ورصد أماكن ضمن نطاق تقريبي 900 متر، وتنبيه مرئي في الصفحة. لا يوجد تتبع موقع مضمون بعد إغلاق التطبيق ولا geofencing يعمل في خلفية iOS.
- اقتراحات مخصصة لنشر محتوى Starbucks Tersane Istanbul على Snap/TikTok/Instagram/LinkedIn/X؛ للمواقع الأخرى قوالب تحتاج بحثًا وتوثيقًا قبل النشر.
- دعم PWA عبر manifest وservice worker.

## مصادر أول مكان

- Starbucks Turkey: https://www.starbucks.com.tr/tersane-flagship-magaza
- متجر Tersane Flagship في قائمة الفروع: https://www.starbucks.com.tr/magazalar

إحداثيات Starbucks الظاهرة في النسخة تجريبية تقريبية؛ يجب التحقق من المدخل المباشر في الخرائط قبل اعتماد الملاحة.

## التحديات التالية

1. فصل المشروع في مستودع مستقل لو رغب المالك.
2. مزامنة اختيارية مع حساب مستخدم/قاعدة بيانات لتوحيد الأجهزة، مع فصل بيانات الرحلة الخاصة عن الموقع العام.
3. مسارات متعددة الوسائط (مترو/ترام/عبّارة) ببيانات GTFS حية أو خدمة توجيه فعلية، وقيود المواعيد والحجوزات.
4. تنبيهات موقع بخلفية النظام عبر تطبيق أصلي إن كانت مطلوبة؛ Web Push وحده لا يوفّر Geolocation مستمر في الخلفية.
5. إحداثيات موثقة وأوقات عمل وفعاليات تستند إلى مصادر وتواريخ.
