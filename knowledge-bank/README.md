# بنك العلاقات والفرص | النسخة الأولى

صفحة مستقلة ضمن services/knowledge-bank. الهوية فقط من mudaraba-to-sjsc/v2:
Craft / TheYearofHandicrafts، #0D3656، #C9853C، الخلفيات والبطاقات والنقشة والفوتر.
لا تنقل المحتوى القانوني أو شعارات المشروع المرجعي. شعار المنصة رمز واجهة مؤقت.

## يعمل الآن
- تجربة بأسماء وبيانات افتراضية، في الذاكرة فقط؛ إعادة التحميل تعيد التجربة.
- مساحة خاصة فارغة: كلمة مرور يختارها المستخدم، PBKDF2-SHA256 (600000) + AES-256-GCM.
- إضافة وتعديل وحذف المعرفة، المصدر والتاريخ والتحقق وإذن المشاركة المقترح.
- بحث عربي، مطابقة اتجاهية بالقواعد، وشرح الترشيح والنواقص، وحفظ الفرصة.
- تتبع التعارف وتوثيق الموافقات يدويا. لا إرسال بريد أو رسائل أو دعوات.
- مهام ومواعيد ومسؤول، واستيراد CSV مع معاينة، ونسخة احتياطية مشفرة واستعادتها.
- قفل تلقائي بعد 15 دقيقة من عدم النشاط، وعدم حفظ المفتاح، ومنع الكتابة فوق تغيير نافذة أخرى.

## غير مفعل
الحسابات المشتركة، المزامنة السحابية، عضويات الدوائر، الدعوات الفعلية، والذكاء الاصطناعي السحابي.
الترشيحات الحالية قواعد أولية، وليست ناتج نموذج لغوي ولا احتمال نجاح أو ربح.
config.js يصرح بهذا صراحة. لم تطبق قاعدة SQL ولم تنشر خدمة معالجة خارجية.
backend/001_owner_schema.sql أساس مستقل بصلاحيات مالك السجل فقط؛ لا يتضمن مشاركة بين الأعضاء.
لتفعيل السحابة: ربط Supabase، اختيار المنطقة ومراجعة سياسة البيانات، تطبيق مخطط مع اختبارات
حسابين وصلاحيات وصول، بناء مهايئ تسجيل الدخول والسجلات، ثم قبول اختبارات التزامن والخصوصية.
لا يوضع service-role أو مفتاح نموذج ذكاء اصطناعي في ملفات الواجهة.

## التشغيل والاختبارات
موقع ثابت دون مكتبات تشغيل خارجية. افتح عبر HTTPS أو localhost، وليس file://.
`python3 -m http.server 8080`
`npm test` و `npm run check`
الخطوط والشعار والنقشة تقرأ من أصول الهوية المنشورة؛ لا يتضمن المشروع نسخا من ملفات الخطوط.

## حدود النسخة
الحفظ محلي في المتصفح وليس حسابا سحابيا. محو بيانات الموقع أو فقد كلمة المرور قد يفقد الوصول.
النسخ الاحتياطية تظل خارج سيطرة الموقع بعد تصديرها. البيانات المستعادة تستبدل مساحة هذا المتصفح بعد تأكيد.
تشفير التخزين لا يحمي من جهاز مخترق أو من شيفرة خبيثة تعمل في الأصل نفسه أثناء فتح المساحة.
قبل بيانات حساسة أو إطلاق متعدد المستخدمين: نطاق مستقل، تدقيق أمني، مراجعة نظامية، واختبار سياسات الخادم.
لا تجمع جهات الاتصال أو البريد أو بيانات الجمعية تلقائيا. المشاركة تحتاج إذنا مناسب للغرض.
