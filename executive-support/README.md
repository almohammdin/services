# مقترح المساعدة الإدارية والتنفيذية

صفحة ونسخة PDF بهوية حتى، مبنيتان على المقترح المقدم من بانا العقاد إلى السيد نايف المحمدي.

المحتوى يحفظ 20 مهمة و6 أسئلة اكتشاف. أعيد تصنيف المهام في6 مجالات، وحذف تكرار فقرة الحوكمة. الرسم العددي يمثل عدد المهام في كل مجال.

## الملفات

- `index.html`: صفحة العرض العربية.
- `style.css`: التنسيق المتجاوب وتخطيط6 صفحات A4 للطباعة.
- `app.js`: الفهرس ومؤشر القراءة والطباعة ونسخ الرابط.
- `content.json`: المحتوى ومطابقته لأقسام المصدر.
- `hatta-executive-support.pdf`: نسخة PDF المكتملة.
- `assets/share-v1.png`: صورة معاينة الرابط بمقاس1200×630.

## إعادة البناء

تستخدم الصفحة أصول الهوية القائمة في `../assets/hatta/` و`../v2/assets/`، بالإضافة إلى وزن Serif900 الأصلي من دليل حتى. لتحديث المحتوى وتصدير PDF وصورة المعاينة:

```bash
python tools/build.py
python tools/render.py
```

يتطلب التصدير WeasyPrint وPyMuPDF. الخطوط مضمنة في PDF، وصورة المعاينة ثابتة.
